# 使用与失败边界（天气—豆粕链）

## 能做什么

- 检验「美豆带天气异常 → DCE 豆粕」这一条链上，天气是否带来超出季节性与已知供需的增量
- 给出滞后区间（天气信息需要多少交易日才体现到豆粕价格）
- 给出失效区间（哪些月份/年份信号无效）
- 如果无增量，交付一个**可复现的负结果**：同口径下「加天气」相对「不加天气」无改善

## 不能做什么

### 品种边界
- 只验证 **DCE 豆粕 M**。不外推到：
  - 棕榈油 P / 豆油 Y：产地降雨机制不同（马来/印尼，且受出口政策干扰）
  - 玉米 C：饲料需求侧与豆粕不同，天气敏感度不同
  - CBOT 大豆：跨市场，需另做时区与传导对齐

### 地域边界
- 只覆盖**美豆带四个州**（IL/IA/NE/MN），约占全球大豆供给 1/3
- 巴西（Mato Grosso）、阿根廷（Pampas）产区**未纳入**。南美天气在 1-3 月是关键期，
  与美豆带 7-8 月互补，但需要另一套数据源与另一段样本

### 频率边界
- 日线口径，**不能**用于日内策略
- 不刻画夜盘跳空传导（若要做，需 5 分钟线，见主线一的时段拆分 skill）

### 时间边界
- 样本从 **2018-01** 起。2016-2017 的归档预报温度全为 0 占位值，不可用
- 因此「跨多个完整厄尔尼诺/拉尼娜周期」这一点做不到：2018-2025 只含一次拉尼娜（2020-2022）

## 已知的数据陷阱

| 陷阱 | 表现 | 处理 |
|---|---|---|
| 再分析前视 | ERA5 是事后修订，直接当信号等于偷看未来 | 主口径用归档预报；再分析只作对照并强制加滞后 |
| 归档预报占位值 | 2016-2017 温度为 0 | 样本从 2018 起 |
| 归档预报极端值 | 实测出现过 120.2mm/日 | ±3σ 缩尾 |
| 预报系统性偏干 | 预报降水异常中位数 -1.43mm | 标准化只用 IS 参数，偏差被吸收 |
| 接口参数不通用 | 库存认 `symbol`，基差认 `underlying_symbol` | 已固化进脚本与 SKILL.md |
| 同日多合约并存 | 主力换月日两个合约都有数据 | 按 `get_future_dominant` 当日映射去重 |
| 令牌并发续期 | 两进程同时续期会互相作废，且不可自愈 | 取数单进程顺序执行 |

## 判为「无增量」的三种情形（都必须如实报告）

1. 天气模型相对 B3（价格+供需）的 OOS Sharpe 提升 < 0.15
2. 增量回归中天气系数 t < 2（含多重检验校正后）
3. 改善只集中在单一年份（如仅 2021 拉尼娜年有效）→ 属事件驱动，非稳定 alpha

出现任一情形，**不得**改口径重跑到「有增量」为止。这是本 skill 的硬约束。
