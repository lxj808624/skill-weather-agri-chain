## 一、最致命的问题：结论强度超过证据

### 任务一

原文把 B2 跳空门控 +13.89% 当正面结论写，但：

- t = **1.01**，bootstrap 95% 区间 **[−0.23, +14.83]**，跨零
- 83 个交易日，σ≈59bp/日 → 80% 功效下最小可测差异约 **18bp/日**，而 B2 只有 5.69bp
- 也就是说：**这份样本根本没有能力支持「跳空门控有效」这句话**

**整改**：新增 §4.5「统计显著性与检验能力」，逐规则给出 MDE 与是否越线；摘要与 README 措辞降级为「未观察到显著优势」；补上样本 B 的关键事实——OOS 里唯一显著的是 B1 仅日盘亏钱（−7.00bp/日，t=−2.58），B0 的 +4.23bp（t=0.92）并不显著。**全研究唯一站得住的统计结论是「日盘内持有亏钱」。**

### 任务二

原文标题写「没有可利用的样本外增量」，这是**存在性断言**，但证据只支持「未发现」。按嵌套回归功效近似：

- 次日 OOS 最小可测 ΔR² ≈ **0.0115**，实际增量 −0.0116
- 一周 ≈0.056，实际 −0.0392
- 一月 ≈**0.15–0.23**（重叠收益使有效样本只剩 30–50 个独立观测），实际 +0.0266

**整改**：新增 §5.5「检验功效」，把结论切成「可以说 / 不能说」三段；摘要改为「在次日与一周窗口未发现；一月窗口功效不足，不下结论」；删掉「一月窗口动量比天气更有用」这类超越功效的排序断言；SKILL 与 README 同步。

**这一条如果被评审先发现，扣的是「方法 35」里最重的一块。自曝比被抓强。**
