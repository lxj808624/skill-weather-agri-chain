## 第 1 次核查（有条件通过）

**三项放行条件，两项不满足：**

1. **`SKILL.md` 的结论表还是旧数字**：写的是 0.0089 / -0.0120 / 1.77 和「最小 p=0.363」，与 Round 2 整改后的 0.0168 / -0.0228 / 1.85、p=0.078 不一致。这属于「报告改了、skill 没改」的典型漏项——复跑者看 SKILL 会拿到错数。
2. **索引里只有 data 与 outputs，没有把 docs / review / scripts 纳入**，索引的实际用途（「拿到包以后从哪读起」）打了折扣。
3. **成本「非模拟赛实测」这句声明只在 `references/cost-model.md` 里**，报告 §2.5 虽有表格但声明不够显眼。

**整改**：SKILL 数字全表同步并加一句「OOS 是 IS 系数套用」的口径说明；报告 §2.5 声明加粗；报告 §8 补「复跑」指引段，指向 SKILL 的四步命令。
