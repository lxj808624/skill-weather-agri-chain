## 方法（35 分）

| 要点 | 做法 |
| --- | --- |
| 真样本外 | IS（2018-01~2022-12）拟合系数，套用到 OOS（2023-01~2025-10）计算 R²，不在 OOS 重拟合 |
| 参数选择不污染样本外 | 15 个 (K, lag) 组合只在 IS 上扫描，OOS 只用于验证 |
| 多重检验 | Benjamini-Hochberg 校正，0/15 通过；最小 p=0.078 |
| 季节性正确编码 | 11 个月份哑变量（基准 1 月），不用连续月份数值 |
| 标准化只用 IS | 均值/方差/缩尾边界均取自 IS |
| 时间对齐 | 信号 t 日收盘可得 → t+1 开盘建仓；库存按周度前向填充，不引入未来值 |
| 稳健性四项 | FDR、扩张窗口滚动、双口径（预报/再分析）、成本覆盖核算 |
| 已知局限的处理 | 库存 2018-09 起点导致 104 天样本差，已披露而非隐藏 |

## 价值验收 V

- 改变了什么决策：把「天气图上看得出来 → 做多农产品」这条常见思路直接否掉；天气对豆粕的样本外 R² 为负，且不通过校正。
- 作用多大：FDR 0/15；逐年 8 年中同一变量出现 3 次以上符号反转；但生长季 vs 非生长季 0.081 vs 0.000 的结构差异成立。
- 适用边界：只对 DCE 豆粕 M、美豆带四州、日频持仓；棕榈油/豆油/玉米/CBOT 均不适用（报告 §11）。
- 可靠负结果：按题目「可靠负结果同样可以形成高价值」计，V 可按 0.60 起评，由负责人确认。
