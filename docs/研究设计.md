# 研究设计：天气—农产品链（美豆带 → DCE 豆粕）

> 任务：D=0.90。须证明加入天气数据后的增量**超出季节性、价格与已知供需信息**。
> 本文档在任何取数/建模之前冻结口径，避免中途改假设（Q15 的教训）。

## 1. 为什么选这条链，而不是航运—商品

题目要求「二选一」，两条都探测过，选天气链的唯一理由是**样本长度**：

| | 天气 → 豆粕 M | 航运 → 集运指数 EC |
|---|---|---|
| 期货可得起点 | 2018-01（可再往前） | 2023-08（EC 上市） |
| 可用交易日 | 约 1900 | 约 550 |
| 样本外可做几折 | 3 折 | 1 折 |
| 发布时点数据 | 归档预报，2018 起干净 | SCFI 周报，周五发布 |
| 已知供需基线 | 库存 + 基差可得 | 无对应库存口径 |

EC 链路更直接，但 550 个交易日做不出题目要求的「样本外改善 + 失效区间」，
因此排除，并把排除证据（BDI 数据源不通、SCFI 可达但样本短）写入报告。
**这是可复现的取舍，不是拍脑袋。**

## 2. 经济链条与作用滞后

```
产区降水/温度异常
   ↓（单产预期，滞后 1~3 个月，7-8 月鼓粒期最关键）
CBOT 大豆
   ↓（压榨利润 + 进口成本，滞后 1~5 个交易日）
DCE 豆粕 M
```

三处滞后必须分开对待：

1. **天气→单产**：不是即时传导。作物在鼓粒期（7-8 月）对水分最敏感，5 月/9 月的
   同量降水影响小得多。→ 用 `is_critical` 月份标记，分季检验。
2. **CBOT→DCE**：夜盘跳空即完成传导，因此 DCE 的**开盘价**已含隔夜信息。
   → 若用当日收盘建仓，等于把传导窗口算进收益，会虚高。本研究一律 **t 日信号 → t+1 日开盘建仓**。
3. **数据发布**：再分析（ERA5）是事后修订的，直接用等于偷看未来。
   → 主口径用**归档预报**（当时发布的快照）；再分析口径只作对照，且强制加 3 天滞后。

## 3. 信号定义（先冻结，再做检验）

对每个交易日 t，取「过去 K 日累计降水异常」与「过去 K 日平均温度异常」：

```
P_K(t) = mean( precip_anom[t-K+1 … t] )        # K ∈ {7, 14, 30}
T_K(t) = mean( temp_anom[t-K+1 … t] )
```

- 异常基准：气候态（同日历日 ±7 天平滑），**只用 t 之前年份的数据**
- 缩尾：±3σ，防归档预报里的极端值（实测出现过 120mm）
- 标准化：只用训练期（IS）的均值方差，OOS 套用训练期参数 → 不前视

**方向假设（先写下来，再看数据打不打脸）**：
- 鼓粒期（7-8 月）降水偏少 → 单产预期下调 → 豆粕偏多
- 鼓粒期高温（T 异常正）→ 单产预期下调 → 豆粕偏多
- 非生长季：天气对豆粕无方向性含义，预期**失效**（这就是「失效区间」的先验）

## 4. 基线（三级，逐级加码）

题目要求证明增量超出「季节性、价格、已知供需」三者。基线因此分三级：

| 级别 | 变量 | 回答的问题 |
|---|---|---|
| B1 季节性 | 月份哑变量 + 趋势 | 天气信号是不是只是「几月该涨」的代理 |
| B2 B1 + 价格 | 20/60 日动量、波动率、前一日收益 | 是不是只是动量的另一种写法 |
| B3 B2 + 已知供需 | 库存（`get_future_inventory`）、基差（`get_future_basis`） | 是不是市场早已知道的信息 |

**判据（前置冻结）**：天气模型相对 B3 的 OOS 改善必须满足
① Sharpe 提升 ≥0.15，且 ② 增量回归里天气系数 t 值 ≥2，且 ③ 分年度不出现「只有一年有效」。
三条缺一即判为**无增量**（负结果同样交付）。

## 5. 检验设计

- **切分**：IS 2018-01~2022-12，OOS 2023-01~2025-10；另做 3 折滚动（walk-forward）
- **滞后扫描**：0/5/10/20/40 交易日，找有效滞后区间，不预设单一取值
- **失效区间**：分生长季/非生长季、分年份，看信号是否只在鼓粒期有效
- **多重检验**：K∈{7,14,30} × 滞后 5 档 = 15 个组合，用 Bonferroni 或 FDR 校正，
  否则「挑最好的一个」必然过拟合
- **交易成本**：豆粕按 1 tick 滑点 + 双边手续费，口径写进 `references/cost-model.md`

## 6. 平台与等价回放

- 取数走平台同源 PandaData MCP（`get_future_daily` / `get_future_inventory` / `get_future_basis`）
- 平台一键运行入口本题沿用主线一的结论：**本机走不通**，改为脚本复跑 + 留痕
- 期货模拟赛：同主线一，本机未连接比赛账户 → 不做实测，**事先声明等价回放范围**
  - 能等价：合约乘数、tick、手续费近似、日线撮合
  - 不能等价：保证金与强平、涨跌停撮合、盘口深度、比赛排名

## 7. 失败边界（预先声明）

- 只在 DCE 豆粕 M 上验证，不外推到油脂、玉米（各品种基本面不同）
- 归档预报 2016-2017 数据不可用（温度为 0 占位），故样本从 2018 起
- 若天气只在 2021（拉尼娜）等极端年份有效，须明确标注为「事件驱动」而非稳定 alpha
- 单一产区（美豆带）覆盖全球大豆供给约 1/3，巴西/阿根廷产区未纳入 → 结论有地域边界
- 日线口径无法刻画日内传导，日内策略不适用
